## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/manisaimuralithatipelli/Web-development-.git
cd Web-development-
```

**Front-end only projects** (`netflix-clone`, `weather-api`, `Project-1` to `Project-6`)
Simply open the corresponding `.html` file in your browser.

> `weather-api` requires an [OpenWeather API](https://openweathermap.org/api) key — add it to the `API_KEY` variable in the JS file.

**Backend projects** (`URL Shortener`, `user-crud-api`, `student-api`)

```bash
cd "URL Shortener"   # or user-crud-api / student-api
npm install
npm start
```

> Each backend project requires its own `.env` file with a `MONGO_URI` — see that project's individual README for details.
