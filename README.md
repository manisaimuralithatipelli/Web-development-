## Overview

This repository is a curated collection of front-end projects and a full-stack mini API, built to practice and demonstrate skills in **HTML, CSS, JavaScript, Node.js, and Express**. Each project is self-contained and can be run independently.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/manisaimuralithatipelli/Web-development-.git
cd Web-development-
```

**Front-end only projects** (`netflix-clone`, `weather-api`, `Project-1` to `Project-6`)
Simply open the corresponding `.html` file in your browser.

> `weather-api` requires an [OpenWeather API](https://openweathermap.org/api) key — add it to the `API_KEY` variable in the JS file.

**Backend project** (`student-api`)

```bash
cd student-api
npm install
npm start
```
