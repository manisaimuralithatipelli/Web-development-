## 🎬 Netflix Clone

A visually appealing Netflix-inspired landing page built using HTML and CSS.  
This project recreates the modern Netflix user interface with a strong focus on clean design, layout structure, and responsiveness.

### ✨ Features
- Responsive design across devices 📱💻  
- Hero section with background image 🎥  
- Styled navigation bar 🍿  
- Movie and series content sections 🎞️  

### 🚀 Purpose
The main goal of this project is to improve frontend development skills and gain practical experience in designing real-world user interfaces.

### ⚠️ Note
This is a static project and does not include backend functionality or real streaming features.
